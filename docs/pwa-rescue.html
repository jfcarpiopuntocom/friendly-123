Antes de desinstalar

No elimines ninguna PWA hasta haber comprobado el respaldo y las ventas, el dinero, el stock y las fotos de esa copia. «Quitar de pantalla de inicio» no es lo mismo que «Eliminar app».

iOS permite múltiples instalaciones de la misma PWA. Cada instalación tiene su propio localStorage, IndexedDB (IDB), caché y sesión. Este rescate solo puede inspeccionar la copia desde la que se abre. No puede leer o desinstalar otra copia remotamente.

Rescate seguro — repetir en CADA copia

  1. Abre cada icono de friendly-123 por separado y anota su etiqueta local de arriba. Revisa a cuál negocio/licencia corresponde después de entrar con el PIN legítimo.
  2. En esa misma copia, entra a Advanced → Backup → Export backup (Avanzado → Respaldo → Exportar respaldo). Guarda el archivo fuera del iPhone y comprueba que se descargó y contiene los datos esperados, incluidas las fotos.
  3. Repite en las otras copias y en el Dashboard, aunque parezcan idénticas. No importes un respaldo antiguo encima de otro: podría sobrescribir movimientos y ventas más recientes. La conciliación debe respetar los IDs de operaciones y la licencia.
  4. Elige la instalación que conservarás solo después de comprobar misma licencia, PIN válido, últimas ventas y fotos, dinero, stock y sincronización en el destino. Si una copia no abre o no se puede autenticar, no la borres.
  5. Cuando la recuperación esté verificada, en la pantalla de inicio o la Biblioteca de apps de iOS mantén pulsado el icono sobrante, pulsa Eliminar app → Eliminar app → Eliminar. No hay permiso web para realizar ese paso automáticamente.

No instales una nueva PWA del dominio antiguo; usa la app oficial tras verificar el respaldo.

Si el icono viejo abre friendly123.com/app o una URL distinta, pertenecía a otro origen. Abrir la web oficial no permite leer el almacenamiento de ese origen antiguo. Primero intenta recuperar la copia original; nunca borres su almacenamiento para «arreglarla».

¿Por qué no hay botón «Uninstall»?

Safari y el sistema operativo no ofrecen una API web para enumerar, fusionar ni eliminar todas las PWAs del iPhone. Un botón que afirmara desinstalarlas sería falso. Aquí tampoco se desregistran service workers, ni se eliminan cachés, IndexedDB o datos del negocio.

El rescate no consulta ni envía PIN, licencia, inventario ni datos comerciales. Solo usa información técnica visible en esta copia y una etiqueta aleatoria local.
